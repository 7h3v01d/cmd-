# 💻 cmd+++ (Archived)
### A tiny Windows batch utility I still use

`cmd+++` is a simple batch script that opens a Windows command prompt **already positioned in the directory you want to work in**.

No setup. No dependencies. No friction.

---

## 🚀 What problem does this solve?

Opening a terminal usually looks like this:

1. Open `cmd`
2. Type `cd /d C:\some\long\path`
3. Repeat all day

`cmd+++` skips step 2.

---

## ✨ What it does

- Launches `cmd.exe` in a predefined or passed directory
- Removes repetitive `cd` commands
- Makes opening a “working shell” a one-step action

It doesn’t replace your shell — it just makes it start *where you actually want to be*.

---

## 🧠 Why this exists

This script was written to remove a small but constant source of friction in daily development.

It’s intentionally:
- minimal
- dependency-free
- durable

The fact that it’s still in use years later says everything.

---

```bat
cmd+++.bat
```
